개인정보 처리방침

시행일: 2026년 11월 20일

TT Wizard는 가입 없이 쓰는 앱이라, 앱에 넣은 과목·시간표·메모는 쓰는 사람의 기기 안에만 있고 개발자에게 오지 않습니다. 개발자가 다루는 개인정보는 서울대학교 수강편람에 공개된 교수 이름과, 사용자가 직접 보내 준 문의 메일 같은 것뿐입니다.

이 방침은 TT Wizard 웹(https://archi142857.github.io/tt-wizard/)과 안드로이드·iOS 앱에 적용됩니다. TT Wizard는 서울대학교 공식 서비스가 아닙니다. 학생 개인이 만든 앱입니다.

1. 처리하는 개인정보

개발자가 처리하는 것

  • 교수 이름: 수강편람에 공개된 강좌의 담당 교수 이름
  • 사용자가 직접 보내 준 것
    • 문의 메일: 보낸 사람의 메일 주소, 메일 내용과 첨부 파일
    • 비공개 테스트 참가 신청: 구글 설문지로 받은 Google 계정 메일 주소와 확인 세 가지(만 14세 이상, 안드로이드 폰, 14일 동안 참여), 또는 테스트용 구글 그룹에 가입한 Google 계정 메일 주소
    • 비공개 테스트 채팅방(카카오톡 팀채팅)에 올린 것: 카카오톡 프로필(이름·사진), 글, 사진
    • Google Play로 보낸 테스트 의견
    • 건네받은 오르막 측정 기록(12절)
    • GitHub 이슈로 남긴 글: GitHub 계정 이름, 글, 앱 정보. 누구나 보는 글입니다(12절)

기기 안에서만 처리하는 것(개발자는 받지 않습니다)

  • 앱에 두는 것: 고른 학기, 담은 과목과 분반, 직접 바꾼 강의실·시간, 출발·도착 지점(기숙사 동처럼 사는 곳을 짐작할 수 있는 곳일 수 있습니다), 동선 탐색 조건과 추가 설정(공강 요일·점심시간), 최근 검색어, 저장한 시간표(학기마다 여러 개), 직접 넣은 일정(이름·요일·시각·장소·메모), 테마 같은 화면 설정. 앱을 다시 열었을 때 이어 쓰려고 기기 저장공간(웹은 브라우저 저장공간)에 두고, 기기 밖으로 보내지 않습니다. 메모도 마찬가지입니다.
  • 기기 백업: 기기 백업을 켜 두었다면 앱에 저장한 내용(담은 과목, 저장한 시간표, 출발 지점 등)이 그 백업(Google 계정·iCloud)에 함께 들어갈 수 있습니다. 개발자는 볼 수 없습니다.
  • 홈 화면 위젯(안드로이드): 위젯이 보여 줄 수 있게 대표 시간표(학기, 시간표 이름, 과목명과 일정 이름, 요일·시각, 강의실, 출발 지점과 걷는 시간, 색)를 앱 저장공간에 두고, 이것도 밖으로 보내지 않습니다. 동선 지도 위젯은 그날 걷는 길과 출발·도착 지점(예: 기숙사 동)을 지도에 그립니다. 위젯은 홈 화면에 보여서 폰 화면을 보는 사람도 볼 수 있습니다. 잠금 화면에는 나오지 않습니다.
  • 시간표 이미지: 이미지로 공유하거나 저장한 그림(PNG) 안에는 학기, 시간표 이름, 과목명·교수명·학점·교과구분·시간·강의실, 직접 넣은 일정의 이름·시간·장소, 색이 글로도 들어가서 받은 사람도 읽을 수 있습니다. 메모는 넣지 않습니다. 그림은 기기에서 만들어 사용자가 고른 곳(사진, 다른 앱)으로만 갑니다. ‘이미지로 추가’는 고른 그림에서 이 자료만 기기 안에서 읽습니다.
  • 링크로 공유: 링크 주소의 # 뒤에 시간표(메모 빼고)가 압축되어 들어갑니다. 암호화하지 않아서 링크가 있는 사람은 누구나 볼 수 있습니다. # 뒤는 서버(GitHub Pages)로 가지 않지만, 링크를 보낸 메신저 대화에는 그대로 남습니다. 받은 쪽도 기기 안에서만 읽습니다.
  • 공유 화면의 앱 단추(안드로이드): 공유 화면에 카카오톡·인스타그램·문자 단추를 보여 주려고 그 앱들이 깔려 있는지 기기 안에서만 확인하고, 그 결과는 어디에도 보내지 않습니다. 단추를 누르면 그 앱의 보내기 화면이 열리고, 그 뒤는 그 앱의 처리방침을 따릅니다.
  • 수업 알림과 계정 기능은 없습니다. 넣게 되면 이 방침을 먼저 고칩니다.

2. 처리 목적

  • 교수 이름: 과목을 찾고(교수 이름으로도 찾을 수 있습니다) 강좌 정보를 보여 주는 데 씁니다. 수강편람에 공개된 그대로 보여 주고, 교수별 평점이나 후기를 모으거나 다른 정보와 합치지 않습니다.
  • 문의 메일과 GitHub 이슈는 답하고 앱을 고치는 데, 테스트 참가 신청은 비공개 테스트 초대에, 테스트 채팅방과 Google Play 테스트 의견은 테스트를 안내하고 의견을 받는 데, 오르막 측정 기록은 걷는 시간 계산이 맞는지 확인하는 데만 씁니다.

4. 보유 기간

  • 교수 이름: 서비스를 운영하는 동안 둡니다. 지난 학기 자료(2021년 1학기부터)도 함께 있습니다.

    • 기기 백업에 들어간 내용은 기기의 백업 설정(Google 계정 백업, iCloud)에서 끄거나 지울 수 있습니다.

  • 의견 보내기: 정보 탭의 ‘의견 보내기’는 쓴 글과 앱 정보(앱 버전, 운영체제, 앱·웹 구분, 보던 학기)를 채운 GitHub 새 이슈 화면을 브라우저로 엽니다. 화면을 열기만 해도 쓴 글이 주소에 담겨 GitHub로 갑니다. 올리기는 쓴 사람이 자기 GitHub 계정으로 하고, 올린 글과 계정 이름은 누구나 볼 수 있습니다. 이때는 GitHub의 약관과 개인정보 처리방침을 따릅니다. 앱이 따로 보내거나 모으는 것은 없습니다. 개인정보가 담긴 글은 메일로 알려 주시면 지우거나 가립니다.

  • 비공개 테스트 채팅방: 테스트 안내와 의견은 카카오톡 팀채팅방에서 주고받습니다. 초대 링크는 구글 설문지를 낸 사람에게만 줍니다. 방에서는 카카오톡 프로필(이름·사진)과 올린 글·사진을 방에 있는 사람 모두가 볼 수 있고, 다른 참가자가 그 프로필로 친구 추가를 할 수 있습니다. 카카오의 약관과 개인정보 처리방침을 따릅니다. 원하지 않으면 들어오기 전에 프로필을 확인해 주십시오. 캡처를 올릴 때는 시간표나 출발 지점처럼 보이고 싶지 않은 것을 가려 주십시오.
