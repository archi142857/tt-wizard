개인정보 처리방침

시행일: 2026년 11월 15일

TT Wizard는 가입하지 않아도 쓸 수 있는 앱입니다. 로그인은 고를 수 있고, 로그인하지 않으면 앱에 넣은 과목·시간표·메모는 쓰는 사람의 기기 안에만 있고 개발자에게 오지 않습니다. 로그인하면 여러 기기에서 시간표를 맞추고 친구와 시간표를 보려고 계정과 시간표 사본을 서버에 둡니다(1절 ‘로그인하면 서버에 두는 것’). 그 밖에 개발자가 다루는 개인정보는 서울대학교 수강편람에 공개된 교수 이름과 비고의 담당자, 그리고 사용자가 직접 보내 준 문의 메일 같은 것뿐입니다.

이 방침은 TT Wizard 웹(https://archi142857.github.io/tt-wizard/)과 안드로이드·iOS 앱에 적용됩니다. TT Wizard는 서울대학교 공식 서비스가 아닙니다. 학생 개인이 만든 앱입니다.

1. 처리하는 개인정보

개발자가 처리하는 것

  • 교수 이름과 비고의 담당자: 수강편람에 공개된 강좌의 담당 교수 이름과, 비고 칸에 적힌 담당자(조교 등)의 이름·메일 주소
  • 사용자가 직접 보내 준 것
    • 문의 메일: 보낸 사람의 메일 주소, 메일 내용과 첨부 파일
    • 비공개 테스트 참가 신청: 구글 설문지로 받은 Google 계정 메일 주소와 확인 세 가지(만 14세 이상, 안드로이드 폰, 14일 동안 참여)
    • 비공개 테스트 채팅방(카카오톡 팀채팅)에 올린 것: 카카오톡 프로필(이름·사진), 글, 사진
    • Google Play로 보낸 테스트 의견
    • 베타 테스터 닉네임: 14일 테스트를 끝까지 함께하고 원한 분이 테스트가 끝날 때 구글 설문지로 보낸 닉네임과, 테스터였는지 확인할 Google 계정 메일 주소
    • 건네받은 오르막 측정 기록(12절)
    • GitHub 이슈로 남긴 글: GitHub 계정 이름, 글, 앱 정보. 누구나 보는 글입니다(12절)

로그인하면 서버에 두는 것(계정과 친구. 로그인은 고를 수 있습니다)

  • 계정: 로그인한 Google 계정의 메일 주소와 고유 번호(uid), 로그인 서비스가 함께 두는 Google 계정 이름과 프로필 사진 주소(앱 화면에는 쓰지 않습니다), 학교 계정(snu.ac.kr)인지
  • 시간표 사본: 학기마다 저장한 시간표(이름, 대표 시간표인지, 담은 과목과 분반, 직접 바꾼 강의실·시간, 색)와 직접 넣은 일정(이름·요일·시각·장소·메모). 여러 기기에서 맞추려고 올립니다. 교수 이름, 출발·도착 지점, 학과·학번, 성적은 올리지 않습니다.
  • 친구 기능을 켜면: 닉네임#번호, 친구 요청·친구·차단 목록, 친구에게 보이는 시간표 사본
  • 접속 기록: 로그인 서비스(Firebase Authentication)가 남기는 IP 주소와 기기·브라우저 정보
  • 친구에게 보이는 것: 서로 수락한 친구에게만, ‘친구에게 보이기’를 켠 학기별 대표 시간표의 과목명·시간·강의실과 직접 넣은 일정의 이름·시간이 보입니다. ‘친구에게 숨기기’를 고른 과목·일정은 이름·강의실 없이 시간만 회색 칸으로 보입니다. 닉네임#번호와 학교 계정 표시(본인이 끌 수 있습니다)는 친구뿐 아니라 친구 요청을 주고받는 사람과 그 닉네임#번호로 찾는 로그인한 사람에게도 보입니다. 장소·메모·학과·학번·성적·메일 주소는 보이지 않습니다.

기기 안에서만 처리하는 것(개발자는 받지 않습니다. 로그인하면 시간표 사본만 위처럼 서버에도 둡니다)

  • 앱에 두는 것: 고른 학기, 담은 과목과 분반, 직접 바꾼 강의실·시간, 출발·도착 지점(기숙사 동처럼 사는 곳을 짐작할 수 있는 곳일 수 있습니다), 동선 탐색 조건과 추가 설정(공강 요일·점심시간), 최근 검색어, 저장한 시간표(학기마다 여러 개), 직접 넣은 일정(이름·요일·시각·장소·메모), 테마 같은 화면 설정. 앱을 다시 열었을 때 이어 쓰려고 기기 저장공간(웹은 브라우저 저장공간)에 두고, 로그인하지 않으면 기기 밖으로 보내지 않습니다. 메모도 마찬가지입니다.
  • 학과와 학번: 처음 켤 때 고르거나 정보 화면에서 고친 주전공과 다른 전공(복수전공·부전공과 선발된 학기), 학번(입학 연도), 학년. 학과·학번·학년 제한이 있는 과목을 알려 주고 졸업 요건을 미리 따져 보는 데 쓰며, 기기에만 두고 밖으로 보내지 않습니다. 지난 시간표가 있으면 그 과목으로 짐작해 미리 채워 두고, 본인이 확인하고 고칩니다.
  • 들은 과목: 졸업 요건 미리 보기를 쓰면, 졸업 요건을 따져 보려고 지난 시간표에서 모아 본인이 확인한 과목 목록을 기기에만 둡니다.
  • 성적: 성적 계산기에 직접 넣은 과목별 성적(A+~F, S·U). 평점을 계산하고, 졸업 요건 미리 보기에서 받은 학점과 졸업 평점을 따지는 데만 쓰며 기기에만 둡니다. 시간표 이미지·링크·캘린더 파일·위젯과 ‘Tachyon으로 보내기’에는 넣지 않습니다.
  • 기기 백업: 기기 백업을 켜 두었다면 앱에 저장한 내용(담은 과목, 저장한 시간표, 출발 지점, 학과·학번, 성적 등)이 그 백업(Google 계정·iCloud)에 함께 들어갈 수 있습니다. 개발자는 볼 수 없습니다.
  • 홈 화면 위젯(안드로이드): 위젯이 보여 줄 수 있게 대표 시간표(학기, 시간표 이름, 과목명과 일정 이름, 요일·시각, 강의실, 출발 지점과 걷는 시간, 색)를 앱 저장공간에 두고, 이것도 밖으로 보내지 않습니다. 동선 지도 위젯은 그날 걷는 길과 출발·도착 지점(예: 기숙사 동)을 지도에 그립니다. 위젯은 홈 화면에 보여서 폰 화면을 보는 사람도 볼 수 있습니다. 잠금 화면에는 나오지 않습니다.
  • 시간표 이미지: 이미지로 공유하거나 저장한 그림(PNG) 안에는 학기, 시간표 이름, 과목명·교수명·학점·교과구분·시간·강의실, 직접 넣은 일정의 이름·시간·장소, 색이 글로도 들어가서 받은 사람도 읽을 수 있습니다. 메모는 넣지 않습니다. 그림은 기기에서 만들어 사용자가 고른 곳(사진, 다른 앱)으로만 갑니다. ‘이미지로 추가’는 고른 그림에서 이 자료만 기기 안에서 읽습니다.
  • 링크로 공유: 링크 주소의 # 뒤에 시간표(메모 빼고)가 압축되어 들어갑니다. 암호화하지 않아서 링크가 있는 사람은 누구나 볼 수 있습니다. # 뒤는 서버(GitHub Pages)로 가지 않지만, 링크를 보낸 메신저 대화에는 그대로 남습니다. 받은 쪽도 기기 안에서만 읽습니다.
  • 캘린더 파일: 공유 화면에서 ‘캘린더’를 고르면 그 시간표를 학기 동안 매주 되풀이되는 일정(과목명과 일정 이름, 요일·시각, 건물·강의실)으로 담은 파일(.ics)을 기기에서 만들어, 사용자가 고른 곳(다운로드, 캘린더 앱, 다른 앱)으로만 보냅니다. 메모는 넣지 않습니다. 앱이 기기의 캘린더를 직접 읽거나 쓰지 않고, 캘린더 앱에 넣은 뒤에는 그 앱의 처리방침을 따릅니다.
  • 공유 화면의 앱 단추(안드로이드): 공유 화면에 카카오톡·인스타그램·문자 단추와 캘린더 파일을 열 수 있는 앱(셋까지)을 보여 주려고 그 앱들이 깔려 있는지 기기 안에서만 확인하고, 그 결과는 어디에도 보내지 않습니다. 단추를 누르면 그 앱의 보내기 화면이 열리고, 그 뒤는 그 앱의 처리방침을 따릅니다.
  • 수업 알림: 정보 화면의 ‘알림’에서 켜면 나갈 시각 몇 분 전에 알리도록 기기 안에서 예약합니다. 편람 알림은 처음부터 켜져 있어, 새 학기 편람이 올라오거나 담은 과목의 시간·강의실이 바뀌었는지 보려고 앱을 열지 않은 때에도 가끔 공개 자료를 받아 기기 안에서 견줍니다(정보 화면에서 끌 수 있습니다). 알림은 기기에서 만들고 알림을 보내는 서버나 알림 토큰이 없어서 개발자에게 가는 것은 없습니다. 알림 내용(과목명, 강의실, 시각)은 잠금 화면에 보일 수 있고, 기기의 알림 설정에서 숨길 수 있습니다.

2. 처리 목적

  • 교수 이름과 비고의 담당자: 과목을 찾고(교수 이름으로도 찾을 수 있습니다) 강좌 정보와 수강 제한 같은 비고를 보여 주는 데 씁니다. 수강편람에 공개된 그대로 보여 주되 비고의 개인 메일 주소는 앱과 웹 자료에서 가리고, 교수별 평점이나 후기를 모으거나 다른 정보와 합치지 않습니다.
  • 문의 메일과 GitHub 이슈는 답하고 앱을 고치는 데, 테스트 참가 신청은 비공개 테스트 초대에, 테스트 채팅방과 Google Play 테스트 의견은 테스트를 안내하고 의견을 받는 데, 오르막 측정 기록은 걷는 시간 계산이 맞는지 확인하는 데만 씁니다.
  • 테스터 닉네임은 앱과 웹의 정보 화면에 함께 만든 테스터로 보여 주는 데 쓰고, 확인용 메일 주소는 테스터였는지 확인하는 데만 씁니다.
  • 로그인한 분의 계정과 시간표 사본, 닉네임, 친구 목록은 여러 기기에서 시간표를 맞추고, 친구 시간표를 보여 주고, 남용을 막는 데만 씁니다. 로그인해 청한 서비스를 하려고 처리합니다(개인정보 보호법 제15조 제1항 제4호).

3. 수집 출처

  • 교수 이름과 비고의 담당자: 서울대학교 수강신청 시스템의 공개 강좌검색(로그인 없이 누구나 보는 화면). 하루 두 번에서 네 번 다시 받아 옵니다.
  • 나머지는 사용자가 메일, 파일, GitHub 이슈, 구글 설문지(테스트 참가 신청, 테스트가 끝날 때 받는 테스터 닉네임), 카카오톡 팀채팅방, Google Play 테스트 의견으로 직접 보내 준 것입니다.
  • 로그인한 분의 계정은 Google 로그인으로 받고, 시간표 사본·닉네임·친구 목록은 앱에서 올린 것입니다.

4. 보유 기간

  • 교수 이름과 비고의 담당자: 서비스를 운영하는 동안 둡니다. 지난 학기 자료(2021년 1학기부터)도 함께 있습니다.
  • 문의 메일: 답을 마치고 1년 동안 둡니다.
  • 테스트 참가 신청(설문 응답과 Play 테스터 목록): 테스트가 끝날 때까지 둡니다.
  • 비공개 테스트 채팅방: 테스트가 끝나면 방을 닫습니다. 방을 닫으면 방의 대화와 사진·파일이 지워집니다.
  • GitHub 이슈: 저장소에 공개로 남습니다. 지워 달라고 하면 지우거나 가립니다.
  • 오르막 측정 기록: 걷는 시간 검증을 마치고 1년 동안 둡니다.
  • 테스터 닉네임: 앱과 웹의 정보 화면에 보이는 동안 둡니다. 확인용 메일 주소는 테스터였는지 확인을 마치면 바로 지웁니다.
  • 로그인한 분의 계정과 서버의 시간표 사본·닉네임·친구 목록: 계정을 지울 때까지 둡니다. 지운 계정과 서버 자료가 Google(Firebase)의 운영·백업 시스템에서 사라지기까지 180일까지 걸릴 수 있고, 접속 기록(IP 주소)은 로그인 서비스가 몇 주 동안 둡니다.

5. 파기 절차와 방법

  • 교수 이름과 비고의 담당자: 보유 기간이 지나거나 정정·삭제를 요청받으면 공개 저장소와 앱 자료에서 지웁니다. 다음 자료 갱신 때 반영됩니다. 다만 코드 저장소의 지난 기록에서는 지우지 않아서, 그 기록에는 남습니다.
  • 사용자가 보내 준 것: 보유 기간이 지나면 메일함, 받은 파일, 설문 응답, 테스터 목록에서 지우고, 테스트 채팅방은 닫습니다.
  • 테스터 닉네임: 지워 달라고 하면 목록에서 빼고 웹의 자료를 다시 올립니다. 앱에서도 자료를 새로 받을 때 빠집니다. 닉네임은 공개 저장소에 올리지 않으므로 저장소의 지난 기록에도 남지 않습니다. 다만 자료를 새로 받기 전까지 기기에 받아 둔 목록과, 다른 사람이 따로 저장한 사본(화면 캡처, 웹 보관소)에는 남을 수 있습니다.
