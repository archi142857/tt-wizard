# 수강 제한 알림

과목·분반에 '수강 제한'·'학번 제한'·'8월 10일부터'·'수강반 제한' 태그를 다는 자료와 계산. update105(2026-11-13), 디자인 121·123판, 프론트엔드 요청 ②, 법무 11/13.

수강편람 엑셀의 **비고** 칸(사람이 쓴 글)을 읽어 분반마다 '언제 누가 신청할 수 있는지'를 단계 규칙으로 바꾸고, 폰이 내 학과·학번과 오늘 날짜로 태그를 고른다. 읽어 낸 규칙이라 틀릴 수 있어서 확실할 때만 태그를 달고, 나머지는 비고 원문을 보인다. 학교의 수강 제한을 대신하지 않는다.

## 흐름

```
수강신청 사이트 ── sync.py ──┬─ 편람 엑셀(data/raw/<학기>_<시각>.xls) ── course_limits.py ── data/limits/<학기>.json
                            └─ 첫 화면 일정표 ──────────────────── update_registration ── data/registration.json
                                                                                              │
export_web.py(표준 라이브러리만) ── 지금 학기 규칙 + 그 학기 일정표 ── web/data/limits.json ── web/js/limits.js(폰 안)
```

- sync.py 는 편람이 바뀌어 원본을 새로 둘 때 그 학기 비고를 다시 읽는다. 읽기가 틀어져도 편람 갱신은 그대로 간다(지난 파일이 남는다).
- 일정표는 돌 때마다(6시간) 그 학기 줄을 모은다. 첫 화면에서 지난 줄이 빠져도 남긴다. `collected` 는 마지막으로 확인한 날(자료 출처의 기준일).
- 웹 자료 만들기(pages.yml)는 엑셀을 못 읽어서(설치 없이 표준 라이브러리만) 규칙은 sync 때 만들어 `data/limits/` 에 둔다.
- 직접 다시 만들기: `python scripts/course_limits.py [--term 2026-2]`(data/raw 의 그 학기 최신 엑셀).

## 자료 꼴

### `data/limits/<학기>.json`, `web/data/limits.json`

```json
{
  "term": "2026-2",
  "read_at": "2026-10-12T14:54+09:00",          // 비고를 읽은 편람을 받은 시각(편람 기준 시각)
  "source": "수강편람 비고", "site": "https://sugang.snu.ac.kr",
  "counts": {"rule": 860, "mark": 464, "note": 397},
  "rules": [ … ],                                // 같은 비고는 규칙 하나를 같이 쓴다
  "sections": {"326.211-001": 0, …},             // "<교과목번호>-<강좌번호>" → rules 차례. 제한이 없는 분반은 없다
  // web/data/limits.json 에만:
  "schedule": {"days": {"1": "2026-08-04", …, "6": "2026-08-11"}, "change": ["2026-08-31", "2026-09-04"], "collected": "2026-08-01"},
  "schedule_source": "서울대학교 수강신청 사이트", "schedule_url": "https://sugang.snu.ac.kr"
}
```

웹 자료는 **지금 학기**(lectures.json 의 학기)만 낸다. 지난 학기는 태그를 달지 않는다(디자인). 지금 학기 규칙이 없으면 파일을 만들지 않고, 옛 파일은 지운다. 일정표가 없으면 `schedule` 은 null.

규칙 하나:

| kind | 뜻 | 화면 |
| --- | --- | --- |
| `mark` | ® 만 있는 분반 | 분반 행에 중립 `수강반 제한` |
| `note` | 제한이 있어 보이지만 확실히 읽지 못함 | 태그 없이 비고 원문(`note`) |
| `rule` | 읽은 단계 규칙(`stages`) + 원문(`note`) | 태그와 대상 글. 모르는 조건이 있으면 원문 |

`note` 는 앞의 ®·ⓔ 를 뺀 원문이고, 개인 메일 주소는 `문의 메일은 수강편람 원문에서`로 바꿨다(법무 11/13). 기관 전화번호·학교 주소·사람 이름이 든 반 이름은 그대로.

단계(`stages`의 한 칸):

```json
{"days": [1, 4], "allow": {…}, "text": "1학년만", "until": "4일차까지 1학년만"}
```

- 구간: `days` [처음, 끝](끝 null = 본 수강신청 끝까지, `through_change` 가 있으면 변경기간까지) · `change: true`(변경기간) · `dates` ["2026-08-04", "2026-08-07"](비고에 날짜로 적힌 것) · 없음(늘) · `rest: true`(밑 규칙: 단계 앞의 'X만'이 단계가 말하지 않는 때에 걸린다)
- `allow`: null 이면 누구나. `who`(이 가운데 하나에 들면 됨) · `except`(들면 막힘) · `grades`/`grade_min`(학년) · `years`/`year_min`/`year_max`(학번) · `first_time`(초수강. 처음 듣는 것으로 본다)
- `who`·`except` 한 칸: `{"name": "생명과학부", "role": "main"|"any", "units": ["u-…"]}` 또는 `{"name", "role", "programs": ["p-…"]}`. id 는 학과 목록(`data/requirements/catalog.json`)의 학과(부)·과정. 단과대는 `college: true` 이고 소속(주전공)으로만 본다
- `text`·`until`: 태그 옆에 보일 짧은 대상 글. 화면은 글을 짓지 않는다(디자인 121판 ②). `until` 은 끝이 있는 단계에만

### `data/registration.json`

```json
{"source": "서울대학교 수강신청 사이트", "url": "https://sugang.snu.ac.kr",
 "terms": {"2026-2": {"collected": "2026-08-01", "rows": [{"type": "선착순수강신청", "start": "2026-08-04", "end": "2026-08-07"}, …]}}}
```

일정표 → 일차(`schedule_of`): SNUTT 처럼 '선착순'(신입생 줄은 빼고)은 본 수강신청, '수강신청변경'은 변경기간. 일차는 그 줄들의 평일(학기 자료의 공휴일 빼고)을 날짜 차례로 1일차부터 센다. 줄 이름에 '(5~6일차)'처럼 일차가 적혀 있고 평일 수와 맞으면 그대로. 날짜는 사실이라 옮겨도 되고 출처 '서울대학교 수강신청 사이트'와 '일정은 바뀔 수 있어요'를 단다(법무 11/13).

## 비고 읽기 (`scripts/course_limits.py`)

띄어쓰기·가운뎃점을 지운 글을 '/'·문장 끝(…가능,)·대괄호로 조각 내고, 조각마다 단계 표시와 대상을 읽는다. 조각 하나라도 읽지 못하면 그 비고 전체를 원문(`note`)으로 둔다.

- 단계 표시: `1~4일차`·`1-4일`·`4일차까지`·`5일차부터`·`5일차~`·`6일차`·`5‧6일차`·`이후에는`(앞 단계 다음 날부터)·`변경기간`·`본 수강신청`·`8/4~8/7`. '장바구니 1~2일차' 는 뺀다
- 대상: 단과대(줄임말 포함), 편람 개설학과 이름과 줄기('경제학 주전공'), 학과 목록의 전공 이름과 줄기('소비자학 주전공생'), '연합전공 X', 주전공·제2전공(복수·부전공), 학년(`3~4학년`, `2학년 이상`), 학번, 초수강, '전체 학생'·'수강반 해제'(밑 규칙까지 푼다), '전 대학'·'전 학년'(학년만 넓힌다), 'A, B를 제외한', 'X 외 수강불가'(= X만), 'X생 수강불허'(= X 제외), '타과생 불허'(개설학과만), '자유전공학부(X 주전공)'·'자유전공학부 X 주전공'(= X 주전공), '(수강대상) …'·'(수강제외) …'
- 안내 조각은 건너뛴다: 문의, 정원 외 신청, 수강기준·텝스, 홈페이지·공지·강의계획서, 담당 교수 일치, 동시수강, 강의실, 주소(http) 등
- 원문으로 두는 것: 따로 뽑기·사전 신청·인터뷰·인턴십·교직 이수처럼 수강신청 사이트 밖에서 정하는 분반, 유학생반·글로벌 인재반, 막는 말과 받는 말이 섞인 비고('음대생 수강 불허(국악과만 수강 가능)'), 학년을 막는 비고('4학년 수강불허'), 같은 단계에 다른 대상(두 판의 글이 이어 붙음), 날짜와 일차가 섞인 비고, 학과 목록에 없는 이름('광역', '진입예정자', '해당전공'), 이수 조건('대학 글쓰기 1 이수', '6학기 이상')
- 막는 쪽은 분명할 때만 넓힌다: 'X생 수강불가'는 X 주전공만 막는다고 본다(제2전공까지 막는다고 적혀 있을 때만 넓힌다). 받는 쪽 역할을 모르면 제2전공도 받는 쪽으로 읽는다. 틀리면 태그가 덜 붙는 쪽으로 틀리게

2026-2 편람(학사 3,936분반 가운데 비고에 제한이 있어 보이는 1,721분반): 규칙 860 · ® 만 464 · 원문 397.

## 태그 고르기 (`web/js/limits.js`)

순수 함수 모듈(requirements.js 처럼). `tests/test_limits.py` 가 node 로 확인한다.

| 함수 | 하는 일 |
| --- | --- |
| `studentFrom(profile, catalog)` | 저장한 학과·학번 `{major: {id, entry}, others: [{kind: "double"\|"minor"\|"major", id, term}], year, grade}` → 계산 꼴. 학과가 없으면 null(규칙이 있는 분반은 원문만). `others` 의 `major` 는 자유전공학부의 주전공(주전공으로 센다) |
| `limitOf(data, 과목번호, 분반, term?)` | 분반 규칙. 다른 학기 자료면 null |
| `sectionTag(rule, student, {today, schedule})` | `{tag, label, text, note, opens}` |
| `courseTag(results)` | 과목 행: 모든 분반이 막히면 `수강 제한`(모두 학년·학번 때문이면 `학번 제한`), 모두 막혔거나 뒤에 열리면 가장 이른 날. 하나라도 지금 열렸거나 모르는 분반(원문·수강반 제한)이 있으면 null |
| `kstToday()` | 한국 시각 오늘 |
| `sourceText(data)` | `수강편람 비고 · 10월 12일 14:54 기준` |
| `scheduleSourceText(data)` | `서울대학교 수강신청 사이트(8월 1일 기준)`(일정표가 없으면 null) |
| `NOTICE`, `NOTICE_DATE`, `noticeFor(results)` | 시트의 분반 목록 위 안내(날짜 태그가 있으면 NOTICE_DATE) |

`sectionTag` 의 규칙:

1. 칸: 일차 규칙은 1~N일차(N = 6, 일정표·비고에 더 있으면 그만큼) + 변경기간, 날짜 규칙은 비고의 날짜 구간들 + 변경기간, 단계 없는 규칙은 '늘' 한 칸
2. 오늘의 칸: 이미 시작한 칸 가운데 마지막(일차 사이 주말, 본 수강신청과 변경기간 사이에는 앞 칸이 이어진다). 시작한 칸이 없거나 일정표가 없으면 첫 칸(수강신청 전). 변경기간이 끝난 뒤는 마지막 칸
3. 칸마다 걸리는 단계: 여럿이면 가장 늦게 시작한 단계('5일차부터'와 '6일차부터'가 겹치는 6일차는 6일차부터), 없으면 밑 규칙, 그것도 없으면 제한 없음
4. 지금 칸에서 막히면: 뒤에 열리는 칸이 있으면 날짜 태그(`8월 10일부터`. 일정표가 없으면 `5일차부터`·`변경기간부터`)와 지금 단계의 `until`, 끝까지 막히면 `수강 제한`(학과·단과대) 또는 `학번 제한`(학년·학번)과 대상 글
5. 모르는 것이 하나라도 걸리면(학과·학년을 안 넣음, 전공 미정인데 전공 단위 규칙, 뒤 칸이 모름) 태그 없이 원문

날짜 태그는 열리는 날 전날까지 보이고, 그날이 되면 사라진다(디자인 121판 ③).

## 화면에서 지킬 것 (법무 11/13, 디자인 121·123판)

- 약하게: 시트 안내 `수강 제한이 있을 수 있어요. 신청 전에 수강신청 사이트에서 확인해 주세요.`(날짜 태그가 있으면 `… 날짜는 바뀔 수 있어요 …`)와 `수강편람 비고 · 8월 4일 09:00 기준`
- 원문 속 주소는 글자 그대로 보이고, 누를 때만 바깥 브라우저로(미리 불러오기·앱 안 웹뷰 없이, 짧은 주소도 그대로)
- 결과 화면·위젯·시간표 이미지·지난 학기에는 달지 않는다
- 수강신청 일정 출처: `서울대학교 수강신청 사이트(기준일)`와 `일정은 바뀔 수 있어요`
- 학과·학번은 기기에만(처리방침 11/27 판 '기기 안' 줄, 그 시행 뒤에 켠다)
