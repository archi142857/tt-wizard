# 화면 캡처

루트 README 에 쓰는 앱 화면입니다. 저장소의 MIT 라이선스 대상이 아닙니다(루트 README '라이선스와 자료 조건').

- 2026-11-16 에 main(34feab1, 판 0.12.0)의 웹 앱을 폰 크기(390×1000)와 컴퓨터 크기(1280×800)로 띄워 찍었습니다(그전 판은 2026-10-30, 7cdeb64). 편람은 2026년 2학기입니다.
- 찍는 법: `python scripts/export_web.py` 로 `web/data/` 를 만들고 그 복사본의 교수 이름을 ○○○ 로 바꿔 띄운 뒤, Chromium(Playwright, 화소 비율 2)으로 찍어 폭 600(컴퓨터는 1600)으로 줄였습니다. 처음 안내·로그인·학과와 학번은 건너뛰었고, 동선 탐색에서 과목 다섯 개를 담아 기숙사 919A동으로 만든 1위 후보를 `시간표 1` 로 저장했습니다.
- `grad.png` 는 학과와 학번을 생명과학부 26학번으로 넣어 본 예시입니다. 들은 과목은 위 2026년 2학기 시간표뿐이고 성적은 넣지 않았습니다.
- 친구 탭은 로그인해야 쓸 수 있어서 찍지 않았습니다.
- 지도에는 바탕 지도의 출처 표기(© 국토지리정보원 · © OpenStreetMap)가 들어 있습니다. 잘라 쓸 때도 이 표기는 남겨 둡니다.
- `image.png` 는 앱의 '이미지로 저장' 결과를 줄인 것입니다. 원래 파일 안에 들어 있던 시간표 자료는 지웠습니다. 2026-11-16 에 같은 시간표를 다시 내보낸 결과가 화소까지 같아서 10/30 파일을 그대로 둡니다.
- 화면이 바뀌면 다시 찍습니다.
