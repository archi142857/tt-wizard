# 화면 캡처

루트 README 에 쓰는 앱 화면입니다. 저장소의 MIT 라이선스 대상이 아닙니다(루트 README '라이선스와 자료 조건').

- 2026-10-30 에 main(7cdeb64)의 웹 앱을 폰 크기(390×1000)와 컴퓨터 크기(1280×800)로 띄워 찍었습니다. 편람은 2026년 2학기입니다.
- 교수 이름은 찍기 전에 ○○○ 로 가렸습니다.
- 지도에는 바탕 지도의 출처 표기(© 국토지리정보원 · © OpenStreetMap)가 들어 있습니다. 잘라 쓸 때도 이 표기는 남겨 둡니다.
- `image.png` 는 앱의 '이미지로 저장' 결과를 줄인 것입니다. 원래 파일 안에 들어 있던 시간표 자료는 지웠습니다.
- 화면이 바뀌면 다시 찍습니다.
