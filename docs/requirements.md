- 계산은 폰 안에서만 한다(`web/js/requirements.js`). 서버도 로그인도 없다.
- 학교 졸업 사정을 대신하지 않는다. 화면 이름은 '졸업 사정'이 아니라 '졸업 요건 미리 보기' 같은 것, 확인 문구는 '학교 공개 문서를 바탕으로 한 추정이며 학번·학과·개별 인정에 따라 다를 수 있음, 최종 확인은 학과와 mySNU'(법무 11/11).

### 과정 파일

```json
{"id": "chem-bio-eng", "college": "공과대학", "unit": "화학생물공학부", "program": "화학생물공학부",
 "depts": ["화학생물공학부"], "code_prefixes": [], "ge_key": "공과대학 화학생물공학부",
 "exists_for": [2019, 2026], "predecessor": null, "structure": {"splits_into": [], "when": null},
 "versions": [
   {"entry_years": [2025, 2026], "basis": "입학 연도",
    "credits": {"grad": 130, "ge": 53, "single": 62, "parallel": 46, "double": 42, "minor": 24, "status": "확인", "src": ["s1"]},
    "status": "확인", "src": ["s2"], "changed": "바로 위 판과 다른 것(옛 판만)",
    "requirements": [
      {"id": "cbe-core12", "type": "major_required", "applies_to": ["single", "parallel"], "text": "전공필수 12과목 33학점",
       "min_count": 12, "min_credits": 33, "courses": [{"code": "458.201", "name": "물리화학 1", "credits": 3}],
       "status": "확인", "src": ["s3"], "note": "…", "extra": {"…": "아직 계산하지 않는 조건"}}]}],
 "change_points": [{"entry_year": 2024, "what": "…"}], "ask_department": ["…"],
 "sources": {"s1": {"title": "…", "url": "https://…", "locator": "쪽·표", "accessed": "2026-11-12"}},
 "checked_on": "2026-11-12"}
```

- **판(versions)**: 같은 규정이 걸리는 학번끼리 묶었다. 판마다 요건 전체를 가진다(조사 자료는 '바로 위 판과 다른 것'만 적고, 가져올 때 펼친다). 판은 2019~2026학번(과정이 있던 학번)을 빈틈·겹침 없이 덮는다.
- **기준(basis)**: 대부분 입학 연도. 다른 것은 전공 진입 연도·다전공 선발 시기·교과 개편 학기·졸업 시기(`졸업_요건_학번별.md` 4절). 이 판의 계산은 입학 연도로만 판을 고른다.
- **상태(status)**: 확인(공식 자료에서 직접 봄) · 부분(봤지만 학번 적용이나 세부가 남음) · 미확인 · 충돌(공식 자료끼리 다름).
- **applies_to**: single(단일전공) · parallel(다른 전공과 병행하는 주전공) · double(다른 학과 학생의 복수전공) · minor(부전공). 비면 모두.
- **전공 과목 알아보기**: 요건 목록에 있거나, 편람 개설 학과가 `depts` 이고 교과구분이 전필·전선(`code_prefixes` 가 있으면 번호 앞자리도). 같은 학부 안 두 전공(식품·동물생명공학부)은 번호 앞자리로 가른다(5252·M1702 = 동물생명공학).
- `extra` 에는 아직 계산하지 않는 조건(여러 갈래, 영역 수, 경로별 학점 등)을 조사 자료 그대로 둔다. 이런 줄은 '확인 필요'.
- **kind**: major(학과·전공) · multi(연합·연계·학생설계 같은 다전공: 여러 학과 과목을 모아 학과 칸이 없고 요건 목록으로만 센다).
- **version_key**: entry(판을 입학 연도로 고름) · selection(판을 다전공 선발 연도로 고름: 연합·연계전공, 학생설계전공(복수전공)). 화면은 selection 과정을 더할 때 선발 학기를 묻는다.
- **exists_for**: 과정이 있던 학번. 1차 조사에만 있는 연합·연계전공(30개)은 모름(null)이고, 판은 선발 연도 2025~2026 하나뿐이다(그 전에 선발된 학생은 '자료 없음').
  2차 조사에만 있는 옛 학과(국사학과·동양사학과·서양사학과 2019~2022, 융합학습과학전공)는 2차 판의 요건 전체로 만들었다.
- `credits.text`: 숫자가 아니라 문장으로 적힌 학점(예: '소속 학과(부)의 다른 전공 병행 학점(최소 39)'). 그 칸 숫자는 null.

### 고치는 법

- 학년도마다(1년 단위, 시점은 사용자가 나중에 정함) 조사를 새로 하고 `requirements_import.py` 를 다시 돌린다. 손으로 고칠 때는 같은 요건이 여러 판에 있으니 판마다 고친다.
- 시범 셋은 `requirements_import.py` 의 `PILOTS` 에 손으로 적은 id·`depts`·`code_prefixes`·`ge_key` 를 쓰고, 나머지는 만들어 넣는다(`--programs all`, 기본).
  - `depts`: 전공 요건 줄(전필·전선·고르기·복수·부전공)의 과목이 지난 편람(`data/history/`)에서 열린 학과 가운데 학과(부)·과정 이름과 같은 것, 없으면 과목의 40% 이상이 열린 학과 하나.
  - `code_prefixes`: 같은 학과를 쓰는 과정이 여럿이면(예: 식품·동물생명공학부의 두 전공) 그 과정 과목에만 나오는 번호 앞자리. 가를 앞자리가 없으면 학과를 비운다(요건 목록으로만 센다, 17과정).
  - 시험이 유도한 값이 시범 셋의 손으로 적은 값과 같은지 본다(`test_derived_depts_match_pilots`).
  - `ge_key`: 대학·학과 이름으로 교양 학점 표의 행을 고른다(`ge_key_for`). 다전공·본과·광역 1학기처럼 표에 행이 없으면 null.
- 2차 자료를 고친 것은 `FIXES`(학생설계전공(복수전공): 2022-1 신청자부터의 판을 선발 연도 2022~2026 으로). 출처의 '레포 data/history/' 꼴 주소는 `repo` 로 바꾸고, 2차 조사가 1차 조사 파일을 가리킨 출처는 뺀다(1차 출처가 이미 표에 있다).
- 시험(`tests/test_requirements.py`): 판이 학번을 덮는지, 요건 id·상태·출처, 판마다 교양 학점 = `ge_credits.json`, 동물생명공학전공의 학번 경계(2021 동물생화학 1·2).

## 2. 계산: `web/js/requirements.js`

| 함수 | 하는 일 |
| --- | --- |
| `pickVersion(program, entryYear)` | 입학 연도의 판. 자료가 없는 학번이면 `{version: null, reason: "no_data"}` |
| `buildSameCourse(courseMap, programs)` | 같은 과목으로 볼 번호(교양 대응표 + 요건의 `alt_codes`) → 대표 번호 |
| `tidyRecords(records, same)` | 들은 과목 정리: 재수강은 옛 수강을 빼고, 표시 없이 두 번이면 `duplicates`(확인 필요), W·드랍과 학사에 안 넣는 대학원 과목은 셈에서 뺀다. F·U 는 학점 0 |
| `evaluateProgram(program, version, courses, {role, sameCourse})` | 요건 줄마다 `met`(충족) · `remaining`(남음, 남은 과목) · `check`(확인 필요, 까닭) |
| `creditSummary(courses, picks, {rules})` | 교양 · 전공(과정마다) · 교직 · 일반선택 · 전체 학점, 두 전공에 걸린 과목(`shared`, 3과목까지), 부전공과 겹친 과목, 다른 학교 학점이 졸업학점 1/2 을 넘는지 |
| `gpa(records, {isMajor})` | 성적 계산기: 전체·전공 평점, 학기별 평점, 직전 2개 정규학기 평점, 졸업 평점(2.0) |
| `gradeNeeded(current, plannedCredits, target)` | 목표 평점에 닿으려면 앞으로 평균 몇이 필요한지 |
| `termCreditLimit(limits, who)` · `withinLimit(courses, lim)` | 학기당 수강 학점 상한과 고른 과목이 그 안인지(상한 밖 과목은 뺀다) |
| `suggestCourses(picks, courses, {sameCourse})` | 다음 학기 추천: 과정마다 `{program, rows}`(evaluateProgram 결과)와 다음 학기 편람(`engine.parseCourses`)에서 남은 요건 과목. 강도 need(남은 과목을 다 들어야 하는 줄) · choose(몇 중 몇) · maybe('확인 필요' 줄의 목록 과목, `row.left`) |
| `rankSuggestions(suggestions, fit)` | 추천 차례(엔진 점수): 강도 → 대표 시간표에 들어가는지 → 늘어나는 비용. `fit` 은 아래 `gapFit` 결과 |
| `engine.gapFit(base, courses, travel, home, {rules, levels, skip})` | 빈 자리 강의 추천: 대표 시간표(분반 목록)에 겹치지 않고 들어가는 과목마다 비용이 가장 덜 느는 분반과 `add = {cost, travel, late, days}`(걷는 분·지각 분·학교 오는 요일, 줄어든 것은 0), `unknownRoom`(강의실 미정)·`atRisk`(폐강 대상). 공강·점심 조건을 주면 지키는 것만, 기본은 학사 과목만. 2026-2 편람 전체를 훑어도 가볍다 |

화면이 쓰는 차례(예): 들은 과목 → `tidyRecords` → 과정마다 `evaluateProgram` → `suggestCourses` → `gapFit(대표 시간표, 추천 과목)` → `rankSuggestions`.
졸업 요건 없이 빈 자리만 볼 때는 `gapFit(대표 시간표, 다음 학기 모든 과목)` 의 `fits` 를 검색 결과에 붙인다('들어감 · 주 +n분').

들은 과목 기록: `{code, name, credits, cls, dept, level, term, status, grade?, source?, toBachelor?}`
- `status`: taken(들음) · failed(학점 못 받음: F·U) · dropped(안 들음: W·드랍) · retake(재수강한 수강)
- `cls`·`dept`·`level`(이수과정: 학사·석사…)은 그 학기 편람에서 화면이 채운다. `source`: snu · exchange · domestic · transfer
- `grade` 는 성적 계산기에서만 쓴다. 없어도 졸업 요건 계산은 된다.

### 학교 규칙 (common.json, 근거는 `학사_공통_규정.md`)

- 학점은 D- 이상과 S 만. 평점은 A+ 4.3 … F 0, S·U·W 는 빼고, 재수강은 나중 성적, 다른 학교 학점은 평점에 넣지 않는다.
- 학기 평점(학기당 학점 늘리기 기준)은 재이수로 조정되기 전 그 학기 성적이고 계절학기는 뺀다.
- 졸업: 130학점, 교양 36·전공 39 이상(과정 값은 판의 학점), 전체·전공 평점 2.0 이상.
- 다전공 겹쳐 인정: 주·복수·연합 공통 인정 전공 과목 최대 3과목(2026-03-01). 부전공·연계·학생설계는 주전공과 겹쳐 인정 없음.
- 학기당 상한(2026-2 기초교양 수강편람): 기본 18, 간호·수의예과 19, 약학 20(2016년 입학자까지)·21(2017년부터), 치의학 학사 21, 의예과 23, 수의학과 25(본과 2022년 1학년부터), 의학과 26.
  첫 학기 예외: 학부대학(자유전공·광역) 첫 1·2학기 20, 자연대 2024년 입학부터 첫 1·2학기 20, 공대 2021년 입학부터 첫 1·2학기 19(광역은 2023년부터 첫 1학기 22), 사범대 2025년 입학부터 첫 1·2학기 19, 첨단융합 첫 1·2학기 20.
  직전 2개 정규학기 평점 3.3 이상이면 21(기본 20 이하인 곳), 학사경고면 15. 상한 밖 과목(E11.108·E31.102·E51.101·E51.102·E52.101·E52.102, 1학기 신입생의 F31.101·F33.101·F34.101·F35.101)은 합에서 뺀다.

## 3. 아직 안 한 것

- 화면(처음 화면의 대학 → 학과(부) → 전공·학번, 들은 과목 확인, 요건 목록, 성적 입력, 추천의 학점 상한)은 디자인·프론트엔드. 화면이 이 모듈을 쓰기 시작하면 `web/sw.js` 의 SHELL 에 `js/requirements.js`·`data/requirements/index.json`·`common.json` 을 더한다(백엔드).
  스토어 앱 묶음에는 화면이 부를 때까지 넣지 않는다(`scripts/build_app.py` 의 `UNTIL_USED`: 다른 HTML·JS 에 `requirements.js`·`data/requirements` 가 보이면 저절로 들어간다, `docs/app.md`).
- **성적은 아직 저장하지 않는다.** 계산 함수만 있다. 성적을 기기에 저장하는 것은 법무 확인 뒤(공유 폴더 `요청_법무.md`), 처리방침 '기기 안' 줄은 기능이 들어가는 판에(문서).
- 판 고르기는 입학 연도만. 전공 진입 연도·다전공 선발 시기·졸업 시기 기준 판, 학과가 허락하는 '더 새 학번 기준으로 보기'는 다음 판.
